🦺 YOLO Vision Engine

This folder contains the computer-vision detection engine for SafeSightAI+.

  • main.py — FastAPI server that runs YOLOv8 detection
  • yolov8n.pt — Current AI model (stock model, not yet trained on construction hazards)
  • requirements.txt — Python packages needed
  • SETUP_WINDOWS.txt — Step-by-step installation guide
Important: This engine must be run on your own computer. It cannot run live on this website. Use the demo video on Google Drive for presentations.

When you train a custom PPE model later, simply replace yolov8n.pt with your trained file and update the model name in main.py. The public GitHub / Vercel link will automatically show the new version.
